# Whisper Small 原版與優化比較

日期：2026-11-02。範圍：獨立 worktree 內的離線實驗，沒有修改產品 runtime 或進行實際跳轉。

## 方法

沿用 Apple M4／24 GiB、Whisper Small 相同模型檔與 Metal backend。四個校準設定為原版 greedy、簡短詞彙提示、beam size 3、beam size 3 加簡短提示。提示只含通用聖經領域詞彙，不包含該筆標準答案或指定章節。使用者接受的目標為最後音節至穩定候選 P95 三秒內；本輪只量測音訊備妥後的 decode、normalization、reference parsing 與必要的 quotation ranking，沒有收音、VAD、IPC 或 UI。

先完成 132 筆 calibration 再固定設定，按主要語言選擇，未新增使用者設定。最終比較保留集與另行製作的 56 筆 challenge。原始 660 筆語料已在前一輪報告分析，故此處的 holdout 是未用於本輪調參的保留集，**不是從未看過的新盲測集**。沒有真人音源；TTS 聲音、發音及模板相關性會影響結果。

拆開兩個變因，提供四組：原版 ASR＋既有解析、優化 ASR＋既有解析、原版 ASR＋優化解析、優化 ASR＋優化解析。文字錯誤率只屬 ASR；定位提升不可宣稱模型本身變準。

- 既有 reference parser/matcher 直接執行目前產品程式。
- 實驗解析補 spoken English／混說的 chapter/verse grammar，沿用既有中文解析，要求書名匹配 score >=0.85 且章節存在。此 score 不是校準後機率。
- quotation 使用與前輪相同的獨立全文檢索 probe，但此次只在 Top-1 similarity >=0.82、與第二名差距 >=0.10，且中文至少 8 units／英文至少 5 words 時接受。兩組使用同一 gate；未使用 expected kind 或 target 決定處理路徑。
- 解析明確章節失敗時不改猜 quotation。錯誤非空候選記為錯誤定位；positive 的拒答仍算未成功。Top-3 recall 與自動接受定位不能混為一談。
- challenge 含各 24 段中文／英文合成非引用音訊及各 4 段 1／3／5／10 秒靜音。其中包含無效章節、日常數字、短宗教片語及明確要求不要跳轉的句子。仍非兩小時講道／音樂風險驗證。

## 校準與固定設定

以下使用同一套優化解析規則；中文正例共 70 筆、英文共 60 筆（含 reference、quotation、mixed），不含 negatives。

| ASR 設定     | 中文正確／錯誤 | 英文正確／錯誤 |
| ------------ | -------------- | -------------- |
| baseline     | 35／1          | 45／9          |
| short-prompt | 33／1          | 53／2          |
| beam3        | 35／1          | 52／4          |
| beam3-short  | 32／1          | 50／4          |

固定決策：中文保留 greedy、無提示；beam3 的總定位收益與原版相同而較慢。英文採 greedy＋簡短提示：正確 45→53/60、錯誤 9→2，優於其餘兩個調整。英文 quotation 單獨則為 18→17/20，故不是所有語料類別都改善。這些數字只用於選設定，不當作正式驗證收益。

中文在最終兩個 ASR 資料集中共用相同推論輸出與耗時，因為設定完全一致；英文重新推論。選擇與定位規則在保留集／challenge 推論前固定，最終測試後不再調整門檻。

## 最終結果與建議

**英文的辨識設定與解析改善值得保留為下一版候選；中文沒有證明提升，不採用本輪一律提高書名門檻的做法。整體不通過自動跳轉驗收。** 離線速度符合三秒，但仍有錯誤候選、中文拒答退步及否定語意誤判，不能用速度通過代替可靠度通過。

### 正確、錯誤與拒答

原版為 baseline ASR＋既有 reference parser；優化為按語言選定 ASR＋實驗 reference parser。quotation gate 在兩組相同，屬獨立 probe，不是現有產品的全文搜尋行為。

| 保留集類別     | 樣本 | 原版正確／錯誤／拒答 | 優化正確／錯誤／拒答 | 正確定位率變化 |
| -------------- | ---: | -------------------- | -------------------- | -------------- |
| 中文口令       |  160 | 99／14／47           | 82／6／72            | 61.9% → 51.2%  |
| 英文口令       |  160 | 43／100／17          | 145／9／6            | 26.9% → 90.6%  |
| 中文朗讀       |   80 | 35／0／45            | 35／0／45            | 43.8% → 43.8%  |
| 英文朗讀       |   80 | 70／1／9             | 72／0／8             | 87.5% → 90.0%  |
| 中文主語言混說 |   40 | 0／2／38             | 6／0／34             | 0.0% → 15.0%   |

英文口令文字 WER 從 5.6% 降至 1.7%；英文朗讀 WER 從 5.4% 降至 4.7%。中文 ASR 設定未變，因此不能宣稱模型中文辨識變準。中文朗讀的嚴格自動接受率只有 35/80，不應拿前輪 99/100 的 Top-3 候選命中率替代。

### 分離模型與解析器的收益

| ASR／解析器        | 英文口令正確／錯誤 | 中文口令正確／錯誤 |
| ------------------ | ------------------ | ------------------ |
| 原版 ASR＋既有解析 | 43／100            | 99／14             |
| 優化 ASR＋既有解析 | 43／101            | 99／14             |
| 原版 ASR＋優化解析 | 115／35            | 82／6              |
| 優化 ASR＋優化解析 | 145／9             | 82／6              |

在相同優化解析器下，英文模型提示帶來的正確定位提升是 115→145/160（+18.75 個百分點），錯誤 35→9；完整路徑 43→145 的收益包含 parser 修正，不能全部歸功於 Whisper。

### 是否增加錯誤跳轉

- 逐筆配對：英文口令總錯誤 100→9，但仍新增 3 筆錯誤，另消除 94 筆原有錯誤。新增錯誤都涉及 `2nd Corinthians`、`2nd Thessalonians`、`2nd John` 的書卷辨識；原本為拒答，優化後選到錯的書卷。不得只看淨減少就宣稱零退步。
- 中文口令減少 8 筆錯誤，卻把原本正確的 17 筆改成拒答。提高 matcher score 門檻並非通用的品質改善。
- 56 筆 challenge 的錯誤候選由 21→10（中文 7→4、英文 14→6）；加上原保留集 8 筆非引用句後，全部 64 筆負例為 22→10。這個人工挑戰集比例不能換算成真實使用每小時誤跳率。
- 最終 10 筆錯誤負例：8 筆「不要翻到／只是範例」仍被當成引用，2 筆「John 在三樓十六號房間」被誤判為 John 16:1。需要明確否定／舉例語意處理與更嚴格的引用語法，不能讓一般人名＋數字觸發定位。
- 兩組 8/8 段靜音都有非空轉錄，但均未產生經文候選。這輪未啟用 VAD；正式收音仍須驗證靜音、音樂與噪聲處理，定位拒答不代表 ASR 沒有幻覺。

### 三秒目標

| 組別 | 語言／樣本 | 離線總處理 P95 |   最慢 | 超過三秒 |
| ---- | ---------- | -------------: | -----: | -------: |
| 原版 | zh／312    |         1.083s | 2.545s |        0 |
| 原版 | en／272    |         0.854s | 1.889s |        0 |
| 優化 | zh／312    |         1.083s | 2.544s |        0 |
| 優化 | en／272    |         0.893s | 1.311s |        0 |

兩組各 584 筆在此離線量測均於三秒內結束，正確定位數也等於三秒內正確定位數。優化組中文 123/280、英文 217/240 的正例在三秒內正確定位；其餘是錯誤或拒答，不能視為成功。這是預先建立索引、音訊已完整可用時的 request 計算時間；不是麥克風到穩定畫面的實測。原版與優化英文為依序執行，未做多次交錯重跑，微小耗時差異不解讀為加速。

### 下一步

1. 保留英文簡短提示與 spoken-number grammar 的方向，但先補 `1st/2nd/3rd` 等 ordinal 書卷解析及多卷書歧義，再用新語料驗證。
2. 不把本輪中文 0.85 全域書名門檻帶入產品；它讓正確定位倒退。中文改採針對書卷的別名／同音候選及歧義檢查，需另做獨立實驗。
3. 先處理不要跳轉、舉例、一般人名＋數字及不完整引用。保留候選確認，尚不建議自動套用所有候選。
4. 加入實際 PCM capture／VAD／穩定候選流程，在真人台灣華語與英文、Windows 11 i7／32 GB 及媒體同時播放情境量測三秒端到端目標。
5. 本輪模型與政策固定後沒有針對最終失敗再修正，以上是後續待驗證項，不宣稱已解決。
