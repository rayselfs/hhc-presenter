# HHC Presenter 2.7.1

This replaces the unpublished 2.7.0 candidate after correcting packaged test setup
for narrow Windows runner displays. Product assertions and timeouts remain unchanged.

This candidate consolidates the project improvement work and legacy feature retirement
before the next ProPresenter implementation phase.

## Changes

- Improve durable file operations, copy snapshots, cleanup rollback and recovery.
- Make Bible expiry cleanup atomic and persist the final copied filename immediately.
- Unify Timer authority, projection ownership and asynchronous resource lifetimes.
- Improve presentation editing, save/reopen, PDF/PPTX navigation and conversion boundaries.
- Remove legacy Service Playlist, Soundboard and MIDI controls. Their saved settings
  remain dormant; legacy routes redirect to Timer. Shared media/audio and slides remain available.
- Apply dependency security fixes and strengthen Browser, source Electron and CI coverage.

## Windows candidate checks

Install the draft Windows executable manually. Use a backup of important presentation data
and synthetic media when exercising deletion or sync conflicts.

- Open existing files and presentations; edit, save, quit and reopen.
- Copy a file beside its original and verify the unique filename after restart.
- Run Timer and stopwatch; browse Bible/media and return to Timer while projecting.
- Import a PPTX, navigate with F5 and arrows, end playback, then reopen projection.
- Play video/audio, pause, seek and adjust volume; confirm audience output and sound.
- Check external displays at 100%, 125% and 150% DPI, including hotplug and focus.
- If using cloud sync, test a dedicated account with synthetic files and verify reconnect.

## Known boundaries

Desktop packages remain unsigned. Follow the operating system's normal trusted-app
approval flow for downloads from the official repository; do not disable platform protection.
Historical invalid documents, Bible cache entries and orphan records are not automatically
repaired. This release does not redefine optimistic edits made during expiry maintenance.

Physical Windows/projector/DPI/audio and live-account acceptance remain pending.
Hosted packaged smoke has the documented macOS live-frame and native-audio limitations.
Keep this release in draft until manual installation checks are accepted. ProPresenter
features are not part of this version.
