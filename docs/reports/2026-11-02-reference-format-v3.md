# Bible reference refusal analysis and v3 grammar

日期：2026-11-02。保留「中文 Turbo、英文 Small」方向。**安全的格式修正有收益，英文接近但尚未達 98%；中文仍主要受語音輸出失真限制，不能再靠放寬書名匹配追分。** 本輪修改只在 benchmark，產品 runtime 尚未更新。

## Refusal causes and changes

上一輪中文口令 226 筆有 72 筆拒答；英文 172 筆有 8 筆拒答。逐筆檢查模型輸出與來源口令，分開處理格式與資訊失真，不把預期書卷灌入解碼或匹配。

| Cause                                                      | Change                                                  | Boundary                                                                  |
| ---------------------------------------------------------- | ------------------------------------------------------- | ------------------------------------------------------------------------- |
| 全句數字正規化破壞書名中的發音字，如「俄八底亞」「個零多」 | 書名部分保留文字，章／節欄位才轉數字                    | 不把書名中的任意數字猜成書卷；明確「第 N 節／章」片語不能充當書名         |
| 中文序數／章節標記的局部失真，如「馬太福音集一章集一節」   | 在完整、精確書名後修正限定標記                          | 不是對整句任意替換；模糊書名加錯誤標記仍拒答                              |
| 模型重複完整相同引用                                       | 僅合併完全相同的引用片段                                | 不同經文、修正句、否定句不能合併成單一候選                                |
| 英文省略 chapter，例如 `Mark 8 verse 3`                    | 接受完整書名＋章號＋明確 verse 標記＋節號               | 不接受缺少欄位、一般房間／樓層數字或無效章節                              |
| 英文數字引用及 Psalm 單數                                  | 明確導航口令下接受點號／空格格式；增加 Psalm 的精確別名 | 無導航前綴的 `John 3.16`／`John 3 16` 保持拒答；不增加英文書名 fuzzy 匹配 |

原書名發音分數／候選差距、章節 bounds、否定與 quotation 門檻保持不變。修正中曾觀察到「第七節書」被發音匹配成書名的風險，已加入結構防護，沒有把這一筆算成收益。防護後續限定為明確序數數字欄位，避免破壞既有「以西節書」等完整書名發音匹配。

## Paired results

M4／24 GiB、Metal、4 threads。中文 Turbo Q5_0／中文 hint／無提示／長句 context 保護；英文 Small／英文 hint／固定簡短提示。先以同一批實際 ASR 輸出比較新舊引用政策，沒有重新挑音訊或排除難辨識聲音。

另實際生成並推論 146 筆新音訊：66 個中文口令涵蓋全部書卷、40 個英文口令、各語言 20 個負例音訊（10 種文字、兩個聲音）。英文 40 個口令中有 20 個刻意省略 chapter，屬格式覆蓋挑戰，不能代表一般使用頻率。正例原文與舊語料去重，沒有因辨識好壞剔除樣本。

| Reference set | Previous policy |            Final v3 | Gain |
| ------------- | --------------: | ------------------: | ---: |
| 中文舊資料    | 154/226 (68.1%) | **161/226 (71.2%)** |   +7 |
| 中文新增挑戰  |   50/66 (75.8%) |   **51/66 (77.3%)** |   +1 |
| 英文舊資料    | 164/172 (95.3%) | **168/172 (97.7%)** |   +4 |
| 英文新增挑戰  |   18/40 (45.0%) |   **39/40 (97.5%)** |  +21 |

不同分布的資料分開列出。若只作算術彙總，中文 212/292（72.6%），英文 207/212（97.6%）；這不是 population accuracy，也沒有達到 98% acceptance。

全部 858 筆回歸／挑戰包含 504 口令、180 朗讀、123 負例與 51 混說。混說非主要語言 gate。逐筆驗證：**33 個新正確候選、零新增錯誤候選、零原正確改為拒答；全部候選仍無錯誤，123 負例全拒答。** 朗讀及混說結果未改變。沒有驅動畫面，因此這是候選政策的離線驗證，不能宣稱現場誤跳率為零。

| ------------ | -----: | ------: |
| 中文舊口令   | 0.958s |  1.690s |
| 中文新增口令 | 0.643s |  0.749s |

858 筆全部在離線三秒內，包含朗讀的全體最慢 2.008 秒。此時間是實測 ASR 加本輪重新量測的正規化與定位；舊資料 ASR 沿用原紀錄，新資料實際推論一次後比較兩種政策。不含收音、VAD endpoint、IPC、UI 或索引冷啟動，不能替代最後音節到穩定預覽的測量。

## Validation chronology

初版規則在新音訊推論前固定。當時新中文為 50/66、新英文為 38/40；之後根據輸出補上 Psalm 別名並縮小過度嚴格的書名欄位防護，得到主表結果。因此**最終新增資料已是調整過規則的挑戰／回歸集，不宣稱獨立盲測**。保留初版規則、初版結果、最終 hash 與逐筆結果，沒有覆寫成「全部事前決定」。

## Chinese decoding experiments

另外實際跑固定中文校準集：40 口令、20 朗讀、10 混說、1 負例，使用相同最終格式規則。

| Turbo decoding           | References /40 | Quotations /20 | Mixed /10 |
| ------------------------ | -------------: | -------------: | --------: |
| Greedy, no prompt        |         **28** |         **15** |         5 |
| Fixed short Bible prompt |             27 |             13 |         5 |
| Beam size 3, no prompt   |             28 |             14 |         5 |

三種設定皆未形成錯誤候選，校準離線時間未超過三秒；但後兩者無品質淨收益，均不採用。Beam 朗讀 P95 約 2.354 秒。基線耗時沿用先前紀錄，不能從不同批次時間差推論精確加速倍率。這些模型設定沒有用新挑戰資料選參數。

## What remains

- 中文剩下 80 個拒答口令，78 個來自 Eddy、2 個來自 Meijia。可見合成聲音偏差很強，但不能刪掉 Eddy 或把另一聲音的高分當成真人準確率。例子包含書名嚴重失真、章／節數字消失、導航前綴變成「請三開」等；缺少可靠資訊時繼續拒答。
- 英文剩下 5 個拒答，均為書名文字失真：Ecclesiast's、Natham（兩筆）、Philippan、Naom。這些不是可直接補齊的引用欄位。尤其人名、近似書名與不同書卷不能靠硬編碼替換預期答案救回。
- 優先保留本輪格式修正。下一步應用核聽完成的真人資料確認中文實際錯誤分布，再針對收音／分段與聲學辨識改善；不繼續只對同一組 TTS 發音堆例外。英文可繼續測獨立語料中的正式書名辨識，但不可放寬成任意模糊英文人名匹配。

16 項 Python tests、34 項 Node assertions、benchmark JavaScript lint、格式與逐筆結果一致性檢查通過。[Evidence](evidence/reference-format-v3-20261102/) 包含可重現政策、初版快照、模型試驗、新合成 corpus 及 raw 輸出；不含私人錄音／AI 逐字稿。[README](../../scripts/speech-benchmark/README.md) 說明重現方式。
