## Implemented scope

The next approved Phase 2 shape-paint increment resolves shape-level `fillRef` solid fills into the existing `fillColor` model. Local fills override references; index 0 means no fill, and indices starting at 1001 select background fill styles. Concrete RGB, mapped theme colors, saved system colors and reference `phClr` substitution are supported. Reference transforms precede matrix transforms, in XML order: linear-light tint/shade, HSL luminance modulation/offset and alpha/set/modulation/offset. Missing colors, invalid indices/numbers and unrepresented transforms produce located compatibility errors rather than guessed paint.

Admission and conversion use the same resolver. Ordinary v1 and explicit v3 conversion gain support; retained-source v2 keeps its existing conversion behavior. No schema, Asset API, default-writer or activation change is included. Source no-op remains byte-exact; an edited fill writes an explicit override while preserving unrelated ZIP members and original theme definitions. This does not implement editable theme definitions, gradients, inherited outlines or effects.

The TypeScript implementation references pinned DeckCraft v0.5.0 `crates/model/src/resolve.rs` and `crates/color/src/lib.rs`; MIT attribution is retained in THIRD_PARTY_NOTICES.md. No dependency was added and no package-private renderer API was imported.
