# HHC Presenter 2.8.0

- Recognize lyrics from camera or capture-card input, preserve line breaks, and project subtitles with adjustable font, size, spacing and bottom margin. Supports manual correction and black-background output for keying.
- Use managed local Chinese and English speech models for Bible lookup on desktop. Download the selected model before going offline. Background audio may require **Finish utterance**, and suggestions that need confirmation stay in preview.
- Improve PPTX import fidelity, editing, snapping, and export. Expand Bible API deadlines to accommodate cold starts.
- Update Electron and build dependencies to address release audit findings.
- Use the official Serwist packages for the web app's offline cache.

Windows x64 and Apple silicon macOS installers are unsigned. Automated package and projection checks exercise synthetic inputs. Physical capture cards, SE-2200 keying, real microphones and extended on-site operation have separate acceptance checks.
