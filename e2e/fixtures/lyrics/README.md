# Lyrics recognition fixtures

The two landscape backgrounds were generated for this investigation. Tests draw original sample sentences over these images at runtime using the application's bundled Noto Sans TC font. No church slide deck, camera frame, or private lyrics catalog is included.

The test deliberately covers two and three lines, bright images with black text, dark images with white text, and black backgrounds. Recognition uses the real, bundled PP-OCRv5 mobile detector and PP-OCRv6 small recognizer, without dictionary corrections or mocked OCR responses.
